** Notes

This is a concept keystone, not a narrative holon — it
has no primary article.  It is the reference that
answers "what is Hoard and how does it work?" through
the system's own mechanisms.

The ordering places the two systems (Hoard, Word-hord)
first, then the concepts in alphabetical order: Cards,
Holons, Overlays, Quads, The Hord, Vocabulary.  A
reader encountering Hoard for the first time can start
with the Hoard card for the overview, then follow the
relationships to understand each component.

This holon deliberately overlaps with Scaffolds.
Scaffolds contains the conceptual substrate (Holarchy,
Homoiconicity, Context) that motivates Hoard's design.
This holon contains the components themselves.  A
reader interested in "why" goes to Scaffolds; a reader
interested in "how" starts here.
