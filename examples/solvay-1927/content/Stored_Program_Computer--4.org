** Scope Note

The concept that instructions and data should reside in
the same memory, allowing programs to modify themselves.
Von Neumann's 1945 "First Draft" report formalized the
architecture.  The machine that emerged from the ruins
of Hilbert's program — built by a man who had watched
the foundations collapse.

** Notes

The stored-program concept was developed independently
by several groups in the mid-1940s.  Von Neumann's
"First Draft of a Report on the EDVAC" (1945) codified
it in a form that became the standard reference.  The
key insight: storing the program in the same memory as
the data it operates on allows the machine to modify
its own instructions — a flexibility that earlier
machines, with their hardwired or externally-fed
programs, could not achieve.

Von Neumann's IAS machine at Princeton — the MANIAC
(Mathematical Analyzer, Numerical Integrator, and
Automatic Computer) — was one of the first
implementations.  The architecture became universal:
fetch instruction, decode, execute, store result.
Virtually every computer built since follows this
pattern.

Von Neumann came to computing from mathematical logic
— the very field Gödel had shown to be incomplete.
Turing had independently defined the limits of what
any such machine could compute.  The stored-program
computer is thus a machine born from the wreckage of
the deterministic dream: powerful beyond anything its
creators imagined, but operating within formal limits
that Gödel and Turing had already proven inescapable.

The EDVAC report remains controversial.  Von Neumann's
name appeared alone on the "First Draft," though J.
Presper Eckert and John Mauchly — who had built ENIAC
and were developing EDVAC — contributed fundamental
ideas.  Herman Goldstine circulated the draft without
their consent, and the resulting priority dispute
poisoned relationships for decades.  Eckert and Mauchly
went on to build UNIVAC; von Neumann built the IAS
machine.  The question of who "invented" the
stored-program computer has no clean answer — it
emerged from a group, and the credit was misattributed
by a clerical accident that became permanent.

The architecture's significance is deeper than speed or
flexibility.  A machine that stores its own program in
memory can modify its own instructions — it can, in
principle, rewrite itself.  This is the computational
analog of self-reference, the very property that Gödel
exploited to prove incompleteness.  It is no accident
that von Neumann, who understood Gödel's proof better
than almost anyone alive, designed a machine with
self-reference as its central feature.

The connection to Turing's universal machine (1936) is
direct.  Turing showed that a single machine, given the
right program, could simulate any other machine — the
concept of universality.  Von Neumann's architecture
made this concrete: a physical device that could be any
computational device, limited only by its memory and
the halting problem that Turing had already proven
unsolvable.  The most powerful machine ever built
carries, in its architecture, the proof of its own
limitations.
